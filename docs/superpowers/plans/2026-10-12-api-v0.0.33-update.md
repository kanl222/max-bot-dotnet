# Обновление MAX.Bot до OpenAPI схемы v0.0.33 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Синхронизировать клиентскую библиотеку MAX.Bot с актуальной спецификацией Max Bot API (OpenAPI v0.0.33), добавив модуль комментариев, управление командами бота, новые типы событий, модели разметки текста, кнопку ClipboardButton и расширенные поля существующих методов.

**Architecture:** Модульная архитектура фасада MaxBotClient с разделением на специализированные модули (Messages, Chats, Members, Attachments, Updates, Subscriptions, Comments). Все модели типизированы с System.Text.Json полиморфной сериализацией и строгой XML-документацией на русском языке.

**Tech Stack:** C# 11, .NET (net8.0, net9.0, net10.0, net462), System.Text.Json.

**Spec:** `D:\Source\MAC-Bot\api-schema\schema.yaml`

## Global Constraints

- Полная совместимость с таргетами: `net8.0`, `net9.0`, `net10.0`, `net462`.
- Обязательная XML-документация на русском языке для всех `public` и `internal` типов, методов и свойств (`code-documentation` skill).
- Обратная совместимость: не ломать существующие публичные сигнатуры (использовать перегрузки или расширения свойств).
